This grid is generated from your shared key. Read it aloud, or glance at it together — if it matches on both screens, no one is in the middle.
Keys are generated fresh in your browser and never leave it — only public keys travel in the invite/reply text. Refreshing the page destroys all keys and history. Files are sent directly over the same encrypted line, in chunks — they aren't relayed anywhere. Local history keeps a note of which files were sent or received, not the file contents themselves. This uses public STUN servers only to help two devices on different networks find each other; no message, key, or file data ever passes through them.
