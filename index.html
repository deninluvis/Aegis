Keys are generated fresh in your browser and never leave it — only public keys travel in the invite/reply text. Files are sent directly over the same encrypted line, in chunks — they aren't relayed anywhere. Voice calls connect the same way: audio streams directly between your two browsers, encrypted end-to-end by WebRTC itself, with call setup messages passed over the already-encrypted data channel. Local history keeps a note of which files were sent or received, and when calls happened, not the file or call contents themselves, kept separately for each contact. This uses public STUN servers only to help two devices on different networks find each other; no message, key, file, or call data ever passes through them. The optional short-code connect mode uses a small relay server to forward the invite/reply handshake automatically instead of copy-paste, and lets a saved contact reconnect later — it still can't read your messages, but unlike hand-to-hand copy-paste it does briefly see each connection setup, so always check the pattern matches on both screens before trusting a line. Contacts made via manual copy-paste can't reconnect automatically and will need a fresh exchange each time. "Forget this line" permanently deletes that saved identity and history from this device.
